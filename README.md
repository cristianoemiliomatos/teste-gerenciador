Este projeto é um sistema de gerenciamento desenvolvido em Python para auxiliar no controle de uma loja ou empresa, com foco em cadastro de clientes, funcionários, produtos, 
vendas e acompanhamento financeiro. A aplicação funciona por meio de menus no terminal, permitindo que diferentes perfis acessem áreas específicas do sistema, como administração,
recursos humanos e atendimento ao cliente.

O sistema permite registrar clientes, cadastrar funcionários, controlar o estoque de produtos, registrar compras, consultar histórico de vendas, acompanhar movimentações financeiras e visualizar relatórios básicos.
Também oferece suporte para listagem de funcionários, remoção de registros e consulta de informações relevantes para a gestão do negócio.

A estrutura do projeto está organizada em módulos, com uma base de dados SQLite para armazenamento das informações. Ele foi pensado como uma solução simples, funcional e de fácil entendimento, ideal para quem está começando no desenvolvimento de sistemas com Python e banco de dados. Além disso, o projeto pode ser expandido com melhorias como autenticação de usuários, cadastro completo de produtos, relatórios mais detalhados, controle de vendas por período e integração com interface gráfica ou web no futuro.
